5. Existing current-code fixes/logic confirmed during review
File: auto_trader_exposure_expansion.py

Confirmed current code has:
- Immediate paper fills return filled=True from executor.
- Immediate filled orders release reserved exposure via _release_exposure().
- Paper flip logic closes old side, books realized PnL, then opens new side using qty // 2.
- Filled paper orders are removed from cycle_orders_sent, so they should not remain as PENDING in same-cycle UI rows.
- symbol_pnl rows combine symbol_realized_pnl + symbol_unrealized_pnl.

Why:
- This addresses the earlier issue where INFY/MARUTI flip orders looked pending and PnL appeared 0.
- It also reduces stale reserved_exposure causing bad portfolio cap values.

If logs show this:
- [LTP-BS] positions success rows=0
  Then Bear Street broker position book has no rows, so poller cannot produce ticks from positions.

- [LTP-BS] missing_ltp symbol=...
  Then position rows exist but do not have ltp/net_price/last_price.

- [LIVE-PNL-TICK] skip_no_position
  Then poller tick arrived, but trader self.positions does not have that symbol.

- [LIVE-PNL-TICK] skip_invalid_position
  Then position exists but qty or entry_price is invalid.

- [LIVE-PNL-REDIS] live_snapshot_empty
  Then Redis publish ran but live_pnl dict has no symbol data.

- [LIVE-PNL-ENDPOINT] ready=false raw_missing
  Then endpoint was hit, but Redis key live_pnl:{session_id} was absent/expired.
